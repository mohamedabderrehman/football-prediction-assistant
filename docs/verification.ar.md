# التحقق من الإصدار الحالي

سجل 2026-10-06 ببيانات محلية مؤقتة. يوثق هذا الملف فحوص التطوير منفصلة عن النشر السابق.

## الفحوص المحلية الناجحة

نجحت اختبارات الخادم الـ21 وفحص TypeScript وبناء الواجهة الإنتاجي. أعاد تحليل المتصفح بيانات مولدة ووضح عدم الاتصال بأي مزود. حُدّث Next.js إلى 15.5.27 لمعالجة تنبيهات أمنية مؤكدة؛ تُسجل نتائج تدقيق الاعتماديات المتبقية منفصلة.

## الأوامر

```sh
cd backend
npm ci
npm run typecheck
npm test -- --run
npm run dev
# Separate terminal:
cd ../frontend
npm ci
npm run dev
npm run build
```

## حالة CI

سُجلت مسارات GitHub Actions لكن المحاولات الأولى انتهت بـstartup_failure قبل إنشاء أي وظيفة أو ملاحظة فحص. النتائج المحلية أعلاه مستقلة عن CI. لا نعرض شارة نجاح ولم توفر الواجهة المتاحة سبباً تفصيلياً.

## حدود المنصة والتغطية

الدرجة الترجيحية تقريبية وغير معايرة؛ لا ندعي دقة تاريخية أو نتيجة رهان آمنة. لم نستخدم نداءات مزود مدفوعة. تبقى نتائج تدقيق اعتماديات أدوات البناء؛ راجع ملاحظة التدقيق.

استُخدم PHP 8.4.26 وNode 24.19 وPython 3.12.10 حيث ينطبق. لا يثبت السجل جاهزية إنتاج شاملة أو فحص مزود مدفوع أو جميع المنصات.
