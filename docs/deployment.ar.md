# النشر وحل المشكلات

## التاريخ

تطبيق بيانات كرة قدم وتحليل بالذكاء الاصطناعي. التقدير الاستدلالي ليس نموذج توقع مُثبتاً.

## البيئة المحلية

استخدم Node 20 أو أحدث. انسخ backend/.env.example إلى backend/.env وفعل FIXTURE_MODE=1 وPORT=3333. ضع NEXT_PUBLIC_API_URL=http://localhost:3333 في frontend/.env.local قبل التشغيل أو البناء. تستخدم العينات Demo United وSample City وتاريخاً ثابتاً. يحتاج الوضع الحي مفاتيح الرياضة والذكاء الاصطناعي في مثال الخادم ولا يحتاج التقييم نداءات مدفوعة.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

الدرجة الترجيحية تقريبية وغير معايرة؛ لا ندعي دقة تاريخية أو نتيجة رهان آمنة. لم نستخدم نداءات مزود مدفوعة. تبقى نتائج تدقيق اعتماديات أدوات البناء؛ راجع ملاحظة التدقيق.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
